MES-RTM 解决的是 SMT 产线**生产执行过程**的数字化管理问题：工单流转、批次追踪、上料齐套、进站/出站、设备状态、质量追溯。

**当前阶段（2026-08）**

- 前端骨架已完整（所有视图页面 + API 层 + Pinia 状态管理 + Element Plus UI）
- 最近持续优化生产模块（批次详情、执行记录、工单视图）和登录体验
- 登录页已移除用户注册功能，改为纯登录入口，UI 重新设计
- 后端服务由 MES-MDM 提供静态数据，RTM 自有后端处理执行数据

**Why:** 原型阶段快速迭代，UI 和 API 同步演进，需要保持跨会话上下文连贯。
**How to apply:** 新会话开始前先读 memory-bank 文件，理解当前迭代方向，避免重复工作。
